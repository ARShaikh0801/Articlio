====================================================
ARTICLIO - GOOGLE SEARCH ME LISTING KARNE KA GUIDE
====================================================

Site: https://articlio-nb11.onrender.com/
Status: Live hai, UptimeRobot configured hai, sitemap.xml aur robots.txt ready hai

Ye guide step by step follow karo, order matter karta hai.


----------------------------------------------------
STEP 1: GOOGLE SEARCH CONSOLE ME SITE ADD KARO
----------------------------------------------------

1. Jao: https://search.google.com/search-console
2. Google account se login karo (jo bhi use karna chahte ho)
3. "Add Property" pe click karo
4. Do options milenge:
   - Domain (agar custom domain hai, DNS verification chahiye)
   - URL prefix (Render ke subdomain ke liye ye use karo)
5. URL prefix me daalo: https://articlio-nb11.onrender.com/
6. "Continue" pe click karo

Verification ke liye options milenge:
   - HTML tag (recommended, easiest)
   - HTML file upload
   - Google Analytics
   - Google Tag Manager
   - DNS record

RECOMMENDED: HTML tag method
   - Google ek meta tag dega jaisे:
     <meta name="google-site-verification" content="xxxxxxxxxxxx" />
   - Ye tag apne base.html template ke <head> section me daal do
   - Deploy karo Render pe
   - Search Console me wapas jao aur "Verify" pe click karo


----------------------------------------------------
STEP 2: SITEMAP SUBMIT KARO
----------------------------------------------------

1. Search Console me left sidebar me "Sitemaps" pe click karo
2. "Add a new sitemap" field me daalo: sitemap.xml
   (Full URL Google khud bana lega: https://articlio-nb11.onrender.com/sitemap.xml)
3. "Submit" pe click karo
4. Status "Success" dikhna chahiye (thoda time lag sakta hai, refresh karte raho)

Agar error aaye:
   - Sitemap URL browser me khol ke check karo ki valid XML return ho raha hai
   - Content-Type header "application/xml" hona chahiye


----------------------------------------------------
STEP 3: ROBOTS.TXT VERIFY KARO
----------------------------------------------------

1. Browser me jao: https://articlio-nb11.onrender.com/robots.txt
2. Confirm karo ki ye lines present hain:

   User-agent: *
   Allow: /
   Sitemap: https://articlio-nb11.onrender.com/sitemap.xml

3. Confirm karo ki koi important page (jaise blog posts, homepage) 
   "Disallow" me nahi hai
4. Sirf admin panel, login-protected pages, ya draft URLs disallow 
   karna chahiye, jaise:

   Disallow: /admin/
   Disallow: /complete-profile/


----------------------------------------------------
STEP 4: MANUAL URL INSPECTION (FAST INDEXING)
----------------------------------------------------

Organic crawling me weeks lag sakte hain, isliye manually push karo:

1. Search Console me top search bar me apna URL paste karo
   (jaise homepage: https://articlio-nb11.onrender.com/)
2. "URL Inspection" tool automatically chalega
3. Agar "URL is not on Google" dikhe, "Request Indexing" pe click karo
4. Yahi process apne top 5-10 important blog posts ke liye bhi karo
5. Google ek queue me daal dega, kuch hours se lekar 1-2 din lag sakte hain

NOTE: Daily quota hoti hai manual requests ki, sab pages ek din me 
mat try karo, top priority pages se start karo.


----------------------------------------------------
STEP 5: ON-PAGE SEO ESSENTIALS CHECK KARO
----------------------------------------------------

Har page pe ye hone chahiye:

[ ] Unique <title> tag (har page ka different, 50-60 characters)
[ ] Unique <meta name="description"> (150-160 characters, page ka 
    summary jo search results me dikhta hai)
[ ] Canonical URL tag:
    <link rel="canonical" href="https://articlio-nb11.onrender.com/post/slug/" />
    (Duplicate content issues avoid karne ke liye)
[ ] Open Graph tags (social sharing ke liye, LinkedIn/Twitter/WhatsApp 
    preview banane ke liye):
    <meta property="og:title" content="..." />
    <meta property="og:description" content="..." />
    <meta property="og:image" content="..." />
    <meta property="og:url" content="..." />
[ ] Proper heading structure (ek hi H1 per page, phir H2, H3 order me)
[ ] Alt text images pe (accessibility + SEO dono ke liye)


----------------------------------------------------
STEP 6: STRUCTURED DATA (JSON-LD) ADD KARO
----------------------------------------------------

Blog posts ke liye "Article" schema add karo, isse Google rich 
results (author, date, image) dikha sakta hai search me.

Example script jo post template me <head> ya body me daalna hai:

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "Post Title Yahan",
  "description": "Post summary yahan",
  "author": {
    "@type": "Person",
    "name": "Author Name"
  },
  "datePublished": "2026-07-08",
  "dateModified": "2026-07-08",
  "image": "https://articlio-nb11.onrender.com/path-to-image.jpg"
}
</script>

Test karne ke liye Google ka Rich Results Test tool use karo:
https://search.google.com/test/rich-results


----------------------------------------------------
STEP 7: PERFORMANCE CHECK (INDIRECTLY RANKING KO AFFECT KARTA HAI)
----------------------------------------------------

1. PageSpeed Insights pe apni site test karo:
   https://pagespeed.web.dev/
2. Mobile aur desktop dono scores dekho
3. Core Web Vitals (LCP, CLS, INP) reasonable range me hone chahiye
4. Render free tier ka cold start issue ho sakta hai, agar 
   Googlebot crawl karte time site "spin up" ho rahi ho to slow 
   response se crawl budget waste ho sakta hai
   (UptimeRobot already configured hai to ye risk kam hai)


----------------------------------------------------
STEP 8: BACKLINKS AUR DISCOVERY BOOST KARO
----------------------------------------------------

Naye site ko Google jaldi trust nahi karta, backlinks help karte hain:

1. Apni site ko share karo:
   - dev.to (article cross-post ya mention)
   - Reddit (relevant subreddits, spam mat karo)
   - Hacker News (Show HN post)
   - Twitter/X, LinkedIn
2. GitHub README me live link already hai, good hai
3. Agar possible ho, kisi dev directory/portfolio site pe list karo


----------------------------------------------------
STEP 9: WAIT AND MONITOR
----------------------------------------------------

1. Naye domain ke liye initial indexing typically 1-4 weeks leti hai
2. Search Console me "Coverage" / "Pages" report regularly check karo
3. Dekho kitne pages "Indexed" hain vs "Excluded"
4. Common exclusion reasons:
   - "Crawled - currently not indexed" (quality/content issue ho sakta hai)
   - "Discovered - currently not indexed" (crawl budget/priority issue)
   - "Duplicate content" (canonical tags check karo)


----------------------------------------------------
BONUS: GOOGLE ANALYTICS (OPTIONAL PAR USEFUL)
----------------------------------------------------

1. https://analytics.google.com pe GA4 property banao
2. Tracking code apne base template me add karo
3. Ye traffic aur user behavior track karega, SEO decisions 
   lene me help karega
